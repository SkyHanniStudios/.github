# SkyHanni Studios

The home of [SkyHanni](https://github.com/hannibal002/SkyHanni), a Fabric mod that adds many useful features to Hypixel SkyBlock, and of the tools around it.

> **On Sunday, October 18**, SkyHanni, SkyHanni-REPO and SkyHanniDevelopment move here from hannibal002. Old links keep working.

## Repositories

| Repository | What it is |
|---|---|
| [SkyHanni](https://github.com/hannibal002/SkyHanni) | The mod itself |
| [SkyHanni-REPO](https://github.com/hannibal002/SkyHanni-REPO) | The data the mod loads on startup |
| [SkyHanniDevelopment](https://github.com/hannibal002/SkyHanniDevelopment) | An IntelliJ plugin that helps when working on the SkyHanni code |
| [SkyHanniChangelogBuilder](https://github.com/SkyHanniStudios/SkyHanniChangelogBuilder) | Builds the SkyHanni changelogs from pull requests |
| [DiscordBot](https://github.com/SkyHanniStudios/DiscordBot) | The bot on the SkyHanni Discord |
